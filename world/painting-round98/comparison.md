# Painted western coast and source review - R98

[Original before/after](comparison.png) · [editable comparison](comparison.svg) · [current painted atlas](atlas.png) · [current terrain atlas](../atlas.png) · [native source study](../western-peninsula-r97.png)

The [official introductory illustration](https://www.ten-sura.com/4GfGdAp7/wp-content/themes/tensura_portal/assets/images/portal-map/world/intro/map-base.webp) shows the western lobe farther west than the northwestern headland. MAP-WES-097 records that visible relationship; DES-WES-097 records the original server adaptation. Copyrighted reference pixels remain linked and privately cached, outside this repository.

R95 had the older coast. R98 follows the current native mainland and four western biome shapes. It reuses the existing original texture through a local SVG mesh and adds restrained light from the current normal heights. The shorter headland and extended lobe are visible in the comparison. The initial narrow texture-clip seams were removed before delivery; neighbouring clips overlap while the exact source coast remains the outer land limit.

The full atlas and enlarged western detail were checked for awkward edges, former-coast remnants, marker drift and text collisions. All 58 marker registrations, 19 context names and 42 open rows retain their prior layout. Pixel differences stay inside the declared western support. No further map.svg correction was identified after this painting review.

The painting remains illustrative. It does not resolve C12 proportions, country/capital footprints, initial buildings or runtime placement. No later event or character is added to the post-Kijin snapshot. See the [full review and limits](README.md) and [independent measurements](audit.json).
