# Official interactive map — live verification

On 20 November 2026 the public [official map](https://www.ten-sura.com/map) was operated in Chrome:
enter, close the tutorial, choose chapter2, advance through all four story stops, switch to World mode,
select Gazel, return, and select Rimuru. Screenshots and the interaction trace remain outside the repo.

Chapter2 links to episodes **9,12,14,15**. It spans both sides of the requested instant, and has no
separate episode10 stop. The [episode10 synopsis](https://www.ten-sura.com/anime/tensura/story/no10)
therefore remains the precise event anchor. A chapter overview is not a frame-accurate snapshot.

Character selection switches to an affiliation-area view. Gazel loads the official
[Gazel overlay](https://www.ten-sura.com/4GfGdAp7/wp-content/themes/tensura_portal/assets/images/portal-map/control/gazel/1.webp);
Rimuru loads the [early village overlay](https://www.ten-sura.com/4GfGdAp7/wp-content/themes/tensura_portal/assets/images/portal-map/control/rimuru/1.webp).
These are linked references only. Marker omissions are storytelling selection, not proof a country
was absent. Highlight shapes are not surveyed borders or permission to annex geographical Jura to
the village. Later chapter screenshots remain separately labelled evidence, not live-tested states.

No copyrighted image, overlay geometry or website code is copied into this repository.
