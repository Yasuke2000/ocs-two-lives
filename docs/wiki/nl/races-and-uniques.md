# Een ras en een Unique Skill kiezen

In de Spirit Corridor neem je twee beslissingen. **Je oordeel bepaalt uit welke lichamen je kunt kiezen. Je laatste wens bepaalt welke vaardigheden je kunt trekken.** Wil je een Slime spelen die vrienden beschermt? Kies eerst **Protection** en kies bij de reïncarnatie **Slime**.

## Welke rassen kan ik krijgen?

Slime staat altijd in het aanbod. Met een hogere rang groeit de verzameling mogelijke rassen en krijg je meer opties te zien. De balans van aantallen en limieten kan veranderen.

| Oordeel | Aantal opties, inclusief Slime | Extra rassen in het gewone aanbod |
| --- | ---: | --- |
| Wanderer | 2 | Goblin |
| Survivor | 3 | Human, Elf, Dwarf, Merfolk, Lizardman, Wight, Ghoul |
| Hero | 4 | Ogre, Harpy, Beastfolk, Giant |
| Legend | 5 | Hobgoblin, Dragonewt, High Orc, Vampire, Lesser Daemon |

Bij Hero komt minstens één aanbod uit de eigen rang, bij Legend minstens twee. Een Fallen-oordeel reserveert ook een plek voor een duister ras. Een Fallen Wanderer kan bijvoorbeeld kiezen tussen Slime en Orc.

## Wat krijg ik voor mijn wens?

Je wens bepaalt de verzameling vaardigheden waaruit wordt getrokken. In de middelste kolom staat telkens één mogelijk resultaat. De laatste kolom geeft de extra keuze die een **Legend** aangeboden kan krijgen.

| Last Wish | Mogelijke vaardigheid | Echo voor een Legend |
| --- | --- | --- |
| Strength | Fighter | Wrath |
| Knowledge | Analyst | Great Sage |
| Protection | Guardian | Creator |
| Hunger | Gourmet | Predator |
| Freedom | Traveler | Sloth |
| Creation | Fusionist | Creator |
| Vengeance | Reaper | Wrath |
| Deceit | Falsifier | Envy |
| Dominion | Commander | Pride |
| Survival | Survivor | Greed |

Als **Wanderer of Survivor** krijg je gewoonlijk één beschikbare vaardigheid toegewezen. Haal je de optionele Trial of the Soul van je wens, dan kies je uit maximaal drie. Als **Hero of Legend** mag je al kiezen dankzij je rang, ook als je de proef overslaat of verliest. Een Legend krijgt bovendien één gewone bonusvaardigheid.

Een Legend kan de echo van de wens kiezen zolang er plaats is. Momenteel kunnen vijf spelers tegelijk dezelfde Common bezitten, drie dezelfde Rare en drie dezelfde Legendary. Serverbreed kunnen tien verschillende spelers een Legendary hebben. Gluttony is Rare. Als alle vaardigheden in je aanbod bezet zijn, kan je reïncarnatie doorgaan zonder Unique. Vult iemand de laatste plek terwijl je kiest, dan kun je een andere optie nemen.

Later kan een speler je vrijwillig een vaardigheid aanbieden met `/ttl absorb bequest <speler> <vaardigheid>`. Je aanvaardt met `/ttl absorb accept <gever>`. Als ontwaakte True Hero of True Demon Lord zie je met `/ttl absorb free` welke Legendaries je kunt claimen. Elke soort ontwaking kun je één keer per ziel inzetten, ook als je intussen via een Reset Counter opnieuw bent geboren. [Karma en rangen](karma.md) · [Verhaal en eed](story-and-oath.md)
