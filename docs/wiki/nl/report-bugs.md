# Een bug melden

Typ in het spel `/bug` met wat je deed, wat je verwachtte en wat er gebeurde. Meld elk probleem apart, zodat het team de oplossing kan opvolgen. Bijvoorbeeld:

```text
/bug In de Spirit Corridor sloot ik het wensmenu en typte ik /ttl menu. Ik verwachtte mijn keuzes terug te zien. De chat bleef leeg en er verscheen geen menu.
```

De server bewaart je melding. Als de koppeling met GitHub beschikbaar is, krijg je in de chat een aanklikbaar meldingsnummer. Daar kun je screenshots of extra uitleg toevoegen. Krijg je bericht dat GitHub de melding niet heeft aangenomen, dan kan een beheerder de kopie op de server nog oppakken.

**Wat wordt openbaar?** Een melding in de openbare GitHub-repository kan je tekst, spelersnaam, precieze locatie, dimensie, gezondheid, voorwerp in je hand, voortgang en recente regels uit het serverlog bevatten. Gaat het om een geheime basis of een gevoelig incident, neem dan eerst privé contact op met Yasuke. Je kunt Yasuke ook vragen een melding te verwijderen. [Meldingen op GitHub](https://github.com/Yasuke2000/ocs-two-lives/issues)

**Kun je niet inloggen?** Met een gekoppeld Discord-account kun je `?bugreport <beschrijving>` gebruiken in `#ideas-and-feedback`. Ben je offline, dan wordt de melding verwerkt zodra je weer inlogt. Verhindert een crash het inloggen helemaal, stuur Yasuke dan de fout uit **Prism → Edit → Minecraft Log** en vertel bij welke stap het misging. Controleer screenshots en logs op privégegevens voordat je ze deelt.
