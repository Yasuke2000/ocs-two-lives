# Report a bug

In game, type `/bug` followed by what you did, what you expected and what happened. One report per problem lets the team follow up on each fix. For example:

```text
/bug In the Spirit Corridor I closed the wish menu and typed /ttl menu. I expected my choices to reopen. The chat stayed empty and no screen appeared.
```

The server saves the report and, when GitHub reporting is available, sends a clickable issue number in chat. Add screenshots or new details to that issue. If you receive a message that GitHub could not accept it, staff can still pick up the server copy.

**What becomes public?** An issue in the project’s public GitHub repository can include your report, player name, exact location, dimension, health, held item, character progress and recent server log excerpts. For a private base location or sensitive incident, contact Yasuke privately first. You can also ask Yasuke to remove a report. [Project issues](https://github.com/Yasuke2000/ocs-two-lives/issues)

**Can’t join?** A linked Discord member can use `?bugreport <description>` in `#ideas-and-feedback`. If you’re offline, the report goes through when you next join. For a crash that stops you joining at all, send Yasuke the error from **Prism → Edit → Minecraft Log**, plus the action that triggered it. Check screenshots and logs for private details before sharing.
