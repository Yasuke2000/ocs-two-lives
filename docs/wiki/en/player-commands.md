# Player commands

Type these commands in Minecraft chat. Replace text inside `< >` with a name, ID or number and leave out the brackets. Commands are the same in either language.

## Getting your bearings

| Command | Use |
| --- | --- |
| `/discordverify` | Request your own link code in game. Enter `/verify <code>` in the server’s Discord. |
| `/ttl guide` | Open the main guide. Use `/ttl guide corridor` or `/ttl guide life2` for a specific guide. |
| `/ttl status` | Check which life or transition you are in. |
| `/ttl life` | Read your personal karma and tier information. |
| `/ttl menu` | Reopen the current Spirit Corridor choice. |
| `/ttl where <place>` | Which way a known place lies and roughly how far (rounded, no coordinates). Tab completes the names, e.g. `/ttl where tempest`. Only works in the Tensura overworld. |
| `/ttl talk` | Speak to the Voice of the World in the Corridor or open the guide elsewhere. |
| `/bug <what happened>` | Send a report from the game. Include what you did and what you expected. |

## Story and exploration

| Command | Use |
| --- | --- |
| `/ttl story` | See your own story progress and Oath. |
| `/ttl story oath` | Open the Oath choice when eligible. |
| `/ttl story talk <npc>` | Request a story character’s dialogue. Use the character ID from the quest. |
| `/ttl story fight <boss>` | Start an eligible fixed fight from nearby. Try `/ttl story fight orc_lord` at the orc camp. |
| `/ttl story capstone` | Finish Act VII after your party has completed the quest and you have earned your own awakening and boss victories. |
| `/ttl rep` | See your faction standings. |
| `/ttl rep renown` | Check your renown. |
| `/ttl favor` | Reopen an outstanding blessing offer. Use `/ttl favor choose <id>` to accept one of its options. |
| `/ttl events mute` | Toggle world-event chat lines for yourself. Event titles remain visible. |

## Parties and nations

| Command | Use |
| --- | --- |
| `/ftbteams party create <name>` | Create an FTB party. Invite a friend with `/ftbteams party invite <player>`. |
| `/ftbteams party join <leader>` | Accept an invitation using the leader’s player name. `/ftbteams party leave` leaves the group. |
| `/ttl party` | Check your party and its shared Oath. |
| `/ttl nation found <name>` | As an eligible Life 2 party owner, buy a nation charter in the overworld. |
| `/ttl nation info` | View your nation. Add a nation name to look it up, or use `/ttl nation top` for the rankings. |
| `/ttl nation deposit <coin> <amount>` | Pay coins into your national treasury. For example, `/ttl nation deposit silver 2`. |

## Guild work and duels

| Command | Use |
| --- | --- |
| `/ttl guild board` | View available contracts. `/ttl guild take <ref>` accepts a listed contract. |
| `/ttl guild status` | Check accepted work. Use `/ttl guild turnin` when ready, or `/ttl guild abandon <ref>` to give up a contract. |
| `/ttl arena list` | See both venues and their current matches. |
| `/ttl arena join <arena> <mode>` | Use `labyrinth` or `walpurgis`, then `duel`, `party` or `challenge`. In a party match, append `a` or `b` to pick a side. |
| `/ttl arena start` | Start the lobby you opened. Use `/ttl arena leave` to withdraw. |
| `/ttl walpurgis status` | Check permission to visit the council. Enter from the dais of Clayman’s throne. |
| `/ttl walpurgis invite <player>` | As a Legendary unique holder, invite an online player to Walpurgis. |
| `/ttl absorb duel <player>` | Invite another Life 2 player to a skill duel. |
| `/ttl absorb accept <name>` | Accept the named sender’s offer. Use `/ttl absorb decline <name>` to refuse. |
| `/ttl absorb free` | See which Legendary uniques are free. An eligible awakened soul can request one with `/ttl absorb claim <skill>`. |
| `/ttl absorb status` | Check your pacts and eligibility for skill transfers. |
